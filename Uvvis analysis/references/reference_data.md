# Dados de referência para UV-Vis

Valores típicos/indicativos (solução aquosa salvo indicação). λmax varia alguns nm com
solvente, pH, concentração (agregação) e equipamento; ε varia entre fontes. Para trabalho
quantitativo, **meça seu padrão**; use estas tabelas para orientar e conferir.
