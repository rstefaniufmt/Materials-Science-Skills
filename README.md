# Materials Science Skills

**A collection of domain-specific AI skills for materials science, spectroscopy, and computational chemistry.**

Materials Science Skills is an open repository dedicated to organizing scientific knowledge, analytical procedures, and domain-specific workflows into reusable skills that can support researchers and AI-powered assistants in scientific tasks.

The project aims to bridge the gap between **scientific expertise and AI-assisted research**, providing structured guidance for the interpretation of experimental data, materials characterization, and chemical analysis.

---

## Overview

Scientific research increasingly involves complex analytical techniques, heterogeneous datasets, and computational workflows. Although general-purpose AI models can assist with scientific tasks, their effectiveness depends heavily on access to reliable domain-specific knowledge and well-defined analytical procedures.

This repository addresses that challenge by providing specialized skills focused on materials characterization and chemical analysis.

Rather than treating AI as a replacement for scientific expertise, the goal is to make established analytical knowledge more accessible, structured, and reusable.

## Available Skills

The repository currently includes the following areas:

| Skill | Scientific domain | Main focus |
|---|---|---|
| **FTIR Analysis** | Infrared spectroscopy | Interpretation of infrared spectra and identification of characteristic vibrational bands |
| **NMR Elucidation** | Nuclear Magnetic Resonance | Spectral interpretation and support for molecular structure elucidation |
| **SEM Carbohydrates** | Materials characterization | Scanning Electron Microscopy applied to carbohydrate-based materials |
| **Thermal Analysis** | Thermal characterization | Interpretation of thermal analysis data |
| **UV-Vis Analysis** | Electronic spectroscopy | Interpretation of UV-Vis spectra and electronic absorption features |

Each skill is organized around a specific scientific domain, allowing the collection to grow modularly as new analytical techniques and research applications are incorporated.

## Design Principles

The project follows a few fundamental principles:

- **Scientific grounding:** AI-assisted analysis should be based on established scientific concepts, analytical methods, and domain-specific knowledge.
- **Modularity:** Each skill addresses a specific analytical domain and can be used independently.
- **Reusability:** Scientific procedures and interpretation guidelines should be reusable across research projects.
- **Transparency:** AI-generated interpretations must remain subject to scientific evaluation and experimental validation.
- **Extensibility:** New skills and analytical domains can be incorporated without requiring changes to existing modules.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/rstefaniufmt/Materials-Science-Skills.git

cd Materials-Science-Skills
```

### 2. Explore the available skills

Browse the directories and select the analytical domain relevant to your research task.

Each skill should be consulted together with its own instructions and supporting materials.

### 3. Use with AI assistants

These skills are intended to support AI-assisted scientific workflows.

Depending on the assistant and its skill-loading mechanism, the relevant skill can be incorporated into the working environment to provide domain-specific instructions and analytical context.

Always check the compatibility and loading requirements of your chosen AI assistant.

### 4. Scientific validation

AI-generated interpretations are intended to support, not replace, scientific reasoning.

Spectral assignments, structural hypotheses, microscopy interpretations, and thermal event analyses should always be evaluated against experimental evidence, appropriate reference data, and established scientific principles.

## Scope and Future Development

Materials Science Skills is designed as an evolving collection.

Potential areas for expansion include:

- Raman spectroscopy
- X-ray diffraction (XRD)
- X-ray photoelectron spectroscopy (XPS)
- Molecular modeling and computational chemistry
- Molecular dynamics simulations
- Density Functional Theory (DFT)
- Materials informatics and machine learning
- Structure-property relationships

Contributions addressing additional analytical techniques, improved scientific interpretation procedures, and reproducible workflows are welcome.
